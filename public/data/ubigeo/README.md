# Catálogo UBIGEO

La aplicación sirve estos archivos localmente para que los formularios no dependan de una conexión del navegador a GitHub. Empresa y productores comparten este catálogo; el servidor comprueba la relación departamento/provincia/distrito y calcula el UBIGEO.
